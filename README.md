#Customer Churn Prediction Using Machine Learning

##Project Overview

Developed a machine learning project to predict customer churn using the IBM Telco Customer Churn dataset.

##Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

##Machine Learning Algorithms

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Support Vector Machine

##Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. Data Preprocessing
4. Feature Scaling
5. Model Training
6. Model Evaluation
7. Data Visualization

##Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
